# BookNest v2 Implementation Plan

> **For agentic workers:** each Track section below is a self-contained brief for one implementer working in its own git worktree. Read the spec first.

**Goal:** better touch selection, immersive full-screen reading, natural-paced audiobook with device voices, and a "Read" shelf.

**Architecture:** no-build PWA (vanilla JS ES modules in `js/`, IndexedDB, vendored pdf.js). The setup commit `61449f2` on `feat/booknest-v2` already provides: per-track CSS files (`css/selection.css`, `css/immersive.css`, `css/tts.css`, `css/shelf.css`, all linked), stub modules wired in `app.js` (`js/reader-touch-select.js` → `initTouchSelect()`, `js/immersive.js` → `initImmersive()`), placeholders in `index.html` (`#immersive-btn` hidden in the reader top bar, `#tts-settings` hidden before `#pdf-scroll`, `#read-shelf` hidden after `#book-grid`), `sw.js` v15 listing those files, and a test port configurable via the `PORT` env var.

**Spec:** `docs/superpowers/specs/2026-10-16-booknest-v2-design.md` (binding).

## Track S — Selection (worktree `feat/v2-selection`, port 4311)

**Owns:** `js/reader-selection.js`, `js/reader-touch-select.js`, new `js/word-geometry.js` (DOM-light helpers; pure word/sentence splitting functions must be importable in node for unit tests), `css/selection.css`, tests `s-*`.

**Must keep working unchanged:** the `selectionchange` handler that positions `#selection-popover` and sets `popover.dataset.text`, `popover.dataset.page`, `popover._rects` (saved-quote rectangles); `buildTextLayer`, `refreshQuoteHighlights`, `clearLiveSelection` exports; popover buttons (Quote/Copy/Define/Translate/Speak). The popover's Speak calls `speak()`/`stopReadAloud()` — leave those calls as they are (Track T owns their implementation and keeps the signatures).

**Deliver:**
1. Pure helpers (unit-tested): `splitWords(text) -> [{start, end, word}]`, `sentenceBounds(text, index) -> {start, end}` (sentence containing index; boundaries `.!?…` followed by space/end; handles quotes/parentheses after punctuation).
2. Anti-jump base: in `buildTextLayer`, append `<div class="endOfContent">` to each text layer; add class `selecting` to the layer on pointerdown inside it, remove on pointerup/cancel; CSS per pdf.js: `.textLayer .endOfContent{display:block;position:absolute;inset:100% 0 0;z-index:-1;cursor:default;user-select:none}` and `.textLayer.selecting .endOfContent{top:0}`.
3. Word snapping: on pointerup after a drag selection inside a text layer, expand the range start/end to whole-word boundaries.
4. Touch gestures in `reader-touch-select.js` (`initTouchSelect()`): long-press (450 ms, < 10 px movement) on a text-layer word selects it (prevent the native long-press selection/callout for that gesture: `contextmenu` preventDefault, and `-webkit-touch-callout:none; -webkit-user-select:none` on `.textLayer` for touch input only — keep mouse selection working); tap on another word while a selection exists extends from the anchor to that word (across pages in continuous mode); double-tap selects the sentence (within one page, across spans/lines); tap outside text clears. Apply as a real DOM Range via `getSelection().removeAllRanges(); addRange(range)` so the existing popover flow runs.
5. Hit-testing a word at a point: use `document.caretPositionFromPoint`/`caretRangeFromPoint` when available, else span rect + proportional offset.

**Tests:** unit for splitWords/sentenceBounds. e2e with `hasTouch: true` context (`test.use({ hasTouch: true, isMobile: true, viewport:{width:800,height:1000} })`), dispatching touch via `page.touchscreen.tap` and CDP or synthetic `pointerdown/pointerup` with `pointerType:'touch'` (long press = pointerdown, wait 500 ms, pointerup): long-press "brown" → popover text "brown"; then tap "lazy" → popover text "brown fox jumps over the lazy"; double-tap a word in "A bird builds a nest." → "A bird builds a nest."; tap empty area → popover hidden; save-as-quote still stores rects. Desktop drag selection test: dragging from mid-"quick" to mid-"fox" yields "quick brown fox".

## Track I — Immersive mode (worktree `feat/v2-immersive`, port 4312)

**Owns:** `js/immersive.js`, `css/immersive.css`, tests `i-*`. May set `#immersive-btn.hidden = false` from JS (don't edit index.html).

**Interfaces available:** `state.reader.mode` ('continuous'|'paginated'), `renderReader()` and `closeReader()` from `js/reader.js`, `$` from `js/dom.js`.

**Deliver (`initImmersive()`):**
1. `#immersive-btn` visible; click → `enterImmersive()`: add class `immersive` to `<body>` (CSS in immersive.css hides `.reader-topbar`, `#page-progress-bar`, `#reader-search-bar`, `#search-progress`, `#search-results`, `#goto-popover`, `#appearance-popover`, `#tts-settings`, `#side-panel`, zoom/appearance floating buttons, `.page-nav`, and makes `#pdf-scroll` fill the viewport; keep `#selection-popover` and `#toast` usable); `document.documentElement.requestFullscreen?.()` (ignore rejection); if mode is paginated, remember it, set `state.reader.mode='continuous'` and `renderReader()`; `history.pushState({immersive:true}, '')`.
2. Exit (`exitImmersive()`) restores everything (mode + re-render if it was switched, `document.exitFullscreen()` if active, remove class) and is triggered by: left→right swipe on `#pdf-scroll` (touch/pointer: dx ≥ 35% of `#pdf-scroll` width, |dy| < 0.5·dx, < 800 ms, no non-empty selection and no long-press in progress — i.e. ignore if the gesture lasted with < 10 px movement for > 400 ms first); `popstate` while immersive (don't let it leave the reader); `fullscreenchange` when `document.fullscreenElement` becomes null while immersive; `Escape` key; and `closeReader` path — if the reader closes while immersive, the class must be removed (observe `#reader-view` losing `view--active` via MutationObserver, or check on `popstate`). Never call `history.back()` twice.
3. First-ever entry: hint toast "Swipe left → right to exit" for 2 s; remember `booknest-immersive-hint` in localStorage.

**Tests (e2e):** button visible in reader; enter → `body.immersive`, topbar hidden, `#pdf-scroll` covers viewport; scroll still works and page counter state updates (check `state` via `#reader-progress` text after exit); synthetic left→right swipe exits; vertical swipe and right→left swipe do not exit; `page.goBack()` exits immersive and stays in the reader (reader view still active); Escape exits; paginated book enters in continuous and returns to paginated on exit; hint shown only once.

## Track T — Audiobook (worktree `feat/v2-tts`, port 4313)

**Owns:** `js/speech.js`, `js/reader-tts.js`, new `js/tts-text.js` (pure, node-testable), `js/tts-voices.js` (voice choice + settings persistence), `css/tts.css`, tests `t-*` and the existing `tests/e2e/c-tts.spec.mjs` / `tests/unit/c-speech.test.mjs` (update as needed). May add ONE settings button right after `#read-aloud-btn` in index.html (`#tts-settings-btn`) and fill `#tts-settings` from JS.

**Keep compatible:** `speak(text, { onend, onerror })`, `stopSpeaking()`, `unlockSpeech()`, `speechSupported` exports from speech.js (used by reader-selection.js's popover Speak, owned by Track S); `stopReadAloud()`, `initReaderTts()` from reader-tts.js; `getPageText(pdfDoc, n)` from reader-search.js (read-only use). Existing guards: generation tokens, skip textless pages without navigating, stop on reader close, iOS unlock in the click handler.

**Deliver:**
1. `tts-text.js`: `cleanPageText(rawText, { prevPageTail?, repeatedLines? })` — join hyphenated line breaks, collapse line breaks to spaces but keep paragraph breaks as `\n\n`, drop lone page numbers and given repeated header/footer lines; `splitSentences(text, max=220)` → `[{text, paragraphEnd:boolean}]` (split long sentences at `;` `:` `,` then word boundary, never mid-word); `detectRepeatedLines(pagesLines)` for headers/footers seen on ≥ 3 sampled pages. Note: `getPageText` joins items with spaces; to see line structure, extract text with `hasEOL` from `page.getTextContent()` items (pdf.js items have `hasEOL`) — add a `getPageLines(pdfDoc, n)` in tts-text or reader-tts (do NOT modify reader-search.js).
2. Speaking queue: one utterance per sentence; pause 250 ms between sentences, 700 ms after a paragraph end, both divided by rate; a sentence whose page text ends without terminal punctuation is joined with the start of the next page's text (and not repeated there).
3. Voices (`tts-voices.js`): wait for `speechSynthesis.getVoices()`/`voiceschanged`; `pickDefaultVoice(voices, lang)` prefers same language, then names matching /natural|neural|google|online/i or `localService === false`; language from `navigator.language` (optionally guess it/en/fr/de/es from stopword counts on the first page text). Settings: voice URI, rate 0.7–1.5 (default 1), pitch 0.8–1.2 (default 1) in localStorage `booknest-tts`.
4. Settings UI: `#tts-settings-btn` toggles `#tts-settings` panel with a voice `<select>` (same-language voices first), rate and pitch sliders with values, and a "Test voice" button; style in tts.css consistent with `.appearance-popover`.
5. Sentence highlight: while reading, add class `tts-current` to the text-layer spans of the current page whose text overlaps the current sentence (normalize whitespace; best-effort), remove on next/stop; scroll it into view inside `#pdf-scroll` if off-screen.
6. Popover Speak uses the same pacing (sentences + chosen voice/rate/pitch).

**Tests:** unit for cleanPageText (hyphen join, paragraph keep, page-number drop, header drop), splitSentences (long sentence split at commas, no mid-word, paragraphEnd flags), pickDefaultVoice (prefers natural same-language). e2e with stubbed speechSynthesis (record utterance text, rate, pitch, voice, and timestamps; fire onend after 20 ms): sentences spoken one per utterance in order; paragraph pause longer than sentence pause (timestamps); rate/pitch from settings applied and persisted across reload; a sentence split across pages spoken once; `tts-current` class present on page 1 while speaking; stop clears it; existing c-tts tests updated and green.

## Track L — Read shelf (worktree `feat/v2-shelf`, port 4314)

**Owns:** `js/library.js`, `css/shelf.css`, library-view markup in `index.html` (`#read-shelf`, `#card-menu` buttons), tests `l-*`. `js/state.js` read-only.

**Deliver:**
1. `renderGrid` splits the filtered/sorted list: not-read books in `#book-grid`; read books (bookStatus === 'read') in `#read-shelf`, rendered as a header button "Read · N" (toggles collapse; state in localStorage `booknest-read-shelf-collapsed`) plus a grid of the same cards with a small "Finished <date>" line (fmtDate(finishedAt)). Hide `#read-shelf` when it has no books after filters. When the status filter is 'read', show only the shelf (expanded); when 'toread'/'reading', hide it. Empty-state / no-results logic must consider both parts.
2. The "Read" status chip (status bar and sidebar shelves) is always shown, even with 0 books.
3. `#card-menu` gains `<button type="button" data-action="toggle-read">` labelled "Mark as read" or "Mark as unread" depending on the book; marking read sets `status='read'`, `startedAt` if missing, `finishedAt=Date.now()`; marking unread removes `status` and `finishedAt`; `DB.put`, re-render, toast "Marked as read" / "Marked as unread" with Undo restoring the previous fields.
4. Select mode and the ⋮ menu work on shelf cards too.

**Tests (e2e):** marking a book read moves it to the shelf with "Read · 1" and a Finished date; persists after reload; Undo restores; mark unread moves back; collapse persists across reload; chip "Read · 0" visible with no read books; status filter 'Read' shows only the shelf; search filters shelf cards; select mode can delete a shelf book.
